# 家庭教育成片驗收

先驗第一支，再擴到整批。參考片約 45 秒。前段用家中動作和短句演出衝突，中段看到孩子的反應及家長換做法，末段由人物面向鏡頭說出一個觀眾可以照做的動作。以 35–45 秒為初稿目標，依實際表演保留必要停頓。

| 關卡 | 看片時確認 | 有問題時 |
|---|---|---|
| 開頭 | 前五秒聽到一句關鍵對白或看到一個具體行為，觀眾知道誰想做什麼 | 把道具或動作提前，剪掉先解說才進情節的開場 |
| 劇情 | 有孩子的反應，家長以可見行動改變局面。正反打方向、人物服裝、道具位置和光線能接上 | 依問題修該鏡。人物漂移用原身份錨點；狀態接不上用上一鏡採用出點的末幀；避免生成後靠字幕解釋缺失的動作 |
| 對白 | 逐句核對話是誰說的、實際字詞、口型和停頓。ASR 用於定位，關鍵句再聽一遍。字幕跟實際音軌對時，手機畫面內可讀 | 錯人開口、關鍵句缺失或錯義，重寫該段的單一講話人和節奏後返修；不可用字幕遮掩 |
| 收束 | 留一個具體做法，可在今晚的相似場景使用。面向鏡頭時眼神穩定。直播或商品只用已核實資訊 | 只保留一條可照做的建議，刪除空泛口號 |
| 媒體 | 開頭、中段、末幀和剪接點無黑幀、錯位、可見模型浮字或關鍵人物被裁。畫幅 9:16，音畫全片可解碼 | 對 768×1344 原片按實際構圖取 756×1344 或安全補邊，再統一輸出規格。保留原始音軌和下載檔 |
| 工坊 | 每集的選題卡指向同批次、同集號的工坊成片，打開播放器確認實際播放，並能看到採用的剪輯段 | 用原清單和渲染回執恢復，避免重建專案或用舊成片代替 |

逐鏡保存集號、鏡號、參考來源、提示詞、任務 ID、下載摘要、實際採用區間和看片判定。若要求全新生成，每段動態畫面都要對應本批次完成的任務和已驗摘要。參考靜幀可作身份錨點。既有片段另標來源，不能計入全新批次。每個失敗鏡頭只改一項主要原因並保留舊版收據，返修結果要再看一次。遇到 queued、in_progress 或提交未知狀態，查原任務和原目錄；收到完整 MP4 且摘要吻合後才剪輯。

成片品質記錄同時保存實際看片結論與技術輸出。工坊的 ideaId、workshopId、renderId、artifactId 及播放結果與當集對齊。技術檢查通過、生成品質通過、人工審核和發布各自有不同證據。

## 已觀察到的返修案例

雙人定妝圖可支援親子對話，但首支試跑把它沿用到單人收尾時，模型在台詞接近正確的情況下，仍在後半段切給孩子。此時把返修範圍限於收尾鏡，改用本批已確認身份的母親單人幀，提示固定單人中近景、直視鏡頭和單一講話人。再檢查開頭、中段和末段，核對整段台詞都由同一人說出。本次返修的六個抽樣畫面都維持母親單人出鏡，語音轉寫保留了「幾點停、怎麼收尾」及「放回固定位置」兩個關鍵動作。抽樣和轉寫的結果與直接聽感分開記錄。

字幕先取一個帶中文的實際畫面渲染小樣，再跑全片。曾遇到系統 FFmpeg 沒有 `ass` 濾鏡，以及 libass 找到字體名卻把漢字畫成方框。先查目前使用的 FFmpeg 濾鏡和字體目錄，挑已驗證的中文字體。把缺字或字體載入錯誤當成失敗，並檢查實際小樣。ASR 若卡在影片封裝的相容性，可先抽 16 kHz 單聲道 WAV 再轉寫，沿用同一影片回執。

首支工坊驗收時，依實際剪輯入出點從每段取開頭、中段和末段，比對工坊下載版與 H3 原片的主要畫面，避開燒錄字幕區。這一步補足技術腳本只能核對「宣告的來源檔」，不能證明那些來源已進入工坊成片的限制。

## 可重跑的工具

Ref2VA 生成使用 [h3-shot.py](../scripts/h3-shot.py)。操作者配置 `EASEL_H3_TOKEN_FILE` 指向本機憑證檔。目錄內放 `prompt.txt`，傳入參考圖和秒數。需要讓出對話等待時間時用 `--submit-only`，之後以相同目錄與參數重新執行，收取原任務。

```bash
.venv/bin/python skills/builtin/family-education-film/scripts/h3-shot.py SHOT_DIR REFERENCE.png 12 --submit-only
.venv/bin/python skills/builtin/family-education-film/scripts/h3-shot.py SHOT_DIR REFERENCE.png 12
```

合成後使用 [verify-film.py](../scripts/verify-film.py) 核對來源收據、唯一任務 ID、生成時間、檔案摘要、畫幅與完整解碼。`--since` 傳本批次啟動的 UTC 時間。剪輯清單另存每段實際入出點；仍需逐集看片、聽音及工坊播放。

```bash
.venv/bin/python skills/builtin/family-education-film/scripts/verify-film.py MASTER.mp4 SHOT_01 SHOT_02 SHOT_03 --since BATCH_STARTED_UTC --output technical-qa.json
```
