# 制作、保真与验收

先选实际可用路径：已授权工坊操作、站内 Host、或用户明确提供的外部部署 CLI。读取当次契约，不从模型品牌名猜能力。不同路径保留各自的任务与鉴权边界；不从本地文件伪造站内批准。

商品特写优先使用实拍图／视频。生成式场景要检查外观、包装、比例、手部交互和商品状态；AI 效果画面不能作为实测、检测或效果比较证据。人物定妆参考与商品参考分别说明用途。连续镜头检查脸、衣服、道具持有者、空间轴线和进出点。

H3 类原声镜头应把准确对白和稳定说话人 ID 放进当前模型接受的提示词。实际参考按真实模态与顺序映射，不引用未上传素材。若使用 I2V，首帧的动作状态要与本段剧本相符；不要让每段都从同一错误姿势重新开始。

生成后保留原片，检查：

1. 文件：真实下载、摘要、视频／音频流、完整解码、量测时长和尺寸。
2. 画面：人脸与服装、商品、手与物体接触、运动连续性、镜头意图、首尾和切点。
3. 声音：准确对白、说话人、音色与情绪、口型、音量、杂音和接缝。
4. 字幕：根据实际语音定时，核对原词、字号、换行和安全区域；先看一张中文字幕预览，防缺字。
5. 商业表达：商品、SKU、参数和价格与来源对应；CTA 入口真实；按目标平台检查 AI、演绎、广告识别及素材许可。

ASR 用于辅助逐字和时间核对，歧义时结合原声与上下文；不能用预先给定的台词强迫识别结果匹配。抽帧不能证明完整动作或声音已经通过；把观察方式和覆盖范围写入 QA。自动审片也应报告模型、目标区间和实际观察，不能冒充真人签署。

可用内部评分帮助排序：剧情25、植入25、商品准确25、视听15、引导10。它是内部初始标准；硬伤必须修复，不用总分抵消商品错误、无依据效果、严重音画问题。

每次采用或返修记录：原任务、模型、请求规格、原片摘要、采用入出点、实测时长、问题、选择原因和最终文件摘要。未知任务只查原 ID；明确失败后的新尝试独立留档，沿用已授权范围并受本次返修上限约束。

接入真实工程时，保存工坊与实际 revision、素材身份、时间线与渲染回执。交付对应具体版本；修改后重新检查。成片放项目根，原片和不采用版本进 assets，不用改名掩盖版本差异。
