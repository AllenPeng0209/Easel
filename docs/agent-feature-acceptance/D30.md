## 具体行为

- 既有发布脚本接收Host生成的固定operationId、payloadHash、平台、模式与批准账号上下文，通过私有原子JSON回执记录未开始、写入尝试、平台ACK和读回。复用已有浏览器/CLI发布流程，没有重写平台自动化。
- 退出码0、日志“成功”、页面跳转或旧版verified均不单独构成公开确认。公众号media_id只记录创建草稿；post ACK/审核中只记录提交。缺证据、身份或关联不一致时保留待核实，不自动重发。
- 公开确认要求同一认证账号、明确的原生作品ACK ID、按该ID唯一匹配、显式公开状态、基线及时间范围的独立认证读回；不从标题前缀猜成功。不把预期账号复制成执行时账号。
- 同操作的晚到观察可从unknown推进，保留观察历史、强结果和固定作品ID，重放幂等。查询不创建新operation，不重新派发发布器；执行中观察不释放账号锁。
- 只有强公开确认投影到本地日历，按operationId/payloadHash去重，投影失败不抹除实际回执。既有脚本不再凭弱UI信号写入“已发布”日历。
- 聊天保留typed publication事件，使用只读回执卡区分尚未批准、执行、草稿、导出、提交、排期、失败、待核实和公开确认。刷新绑定同用户/IP/批准对象/账号/内容摘要/操作，晚到ACK可更新，错配或旧结果不冒充新结果。
- Codex新增仅接受approvalId的easel_publication_status；新线程注册，已注册线程可独立进程恢复；未注册该工具的旧线程仍使用界面查询或显式新建，不能在resume静默追加工具。
