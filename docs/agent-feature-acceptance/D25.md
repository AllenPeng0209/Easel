## 行为

- 在聊天中查询已保存选题、当前账号与IP的固定稿件文件、工坊项目。服务端复用选题目录、D08 ChatArtifactStore和WorkshopStore，不新建平行业务数据库。默认20项游标可遍历全部，游标绑定actor/IP/kind/query；历史安全选题ID可从list继续inspect。选题观测摘要不是虚构的业务revision。
- Host返回白名单DTO和真实来源、ID、revision/sha及合法导航。HTTP刷新、Native回包和SSE使用同一个公开投影：已知本机配置值先遮盖，再计算观测摘要；不改原业务记录。可显示摘要长度有边界，原记录仍可从业务页查看。跨账号、跨IP、viewer、权限撤销和伪造额外字段均由服务端拒绝。
- Native `easel_business_objects` 只接受只读list/inspect及真实实体参数，保留真实callId；同回合同调用重放去重、改参数拒绝。新线程注册，已有定义跨进程恢复；resume不追加工具。未知、拒绝和无终态的工具不会被视为业务成功。
- 专用卡展示固定稿件、真实项目/导出/成片/审阅记录和可核对状态。导出成功未收取不是成片已交付，历史或模拟审阅不是人工当前批准。工坊卡不外联引擎核验，也不凭历史记录宣称可发布。发布回执仍归07。
- 卡内Markdown/文本预览只读固定artifactId，使用既有认证读取和惰性纯文本展示；源文件改版不替换旧稿。内联读取上限1MiB，超限提供固定版本下载；HTML继续原D08 sandbox。失败/404保留历史观测或提供重试，不回退到可变当前路径。
- 选题及工坊导航先做活体授权查询，再按指定ID精确定位；不存在时不打开其他对象。工坊深链进入交付与审阅，观察已有导出不会自动收取；用户明确点击后才由既有服务执行。此功能不新增自动审核、制作或发布权限。
