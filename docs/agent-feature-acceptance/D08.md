# D08 · 不可变交付版本验收

日期：2026-11-03。状态：固定版本存储、历史、预览与下载已验收；本记录随D08功能独立提交。原始D08的批准绑定部分仍需B30/D30，不标整行完全关闭。

## 原始范围

交付必须固定 artifactId、revision、sha256；修改或删除源文件不能改变旧版本。历史交付、最新交付与当前磁盘文件不可混称；批准只能关联真实指定版本。本功能完成后独立commit，B30/D30的发布批准联动仍按原需求继续，不能用“未审核”默认值冒充已批准闭环。

## 必须验证

- 旧D01数据库保留ID/行，标legacy-current，不伪造历史hash。
- 新版本根文件和支持的本地HTML依赖在present时捕获；源文件改写/删除后原ID仍取原字节。
- 同调用幂等不重拍后来源，变更参数冲突；A→B→A为独立revision，可复用内容blob。
- 复制中变化、取消、磁盘/DB失败不得宣告成功或留下可见半版本；blob损坏不得回退读取当前源。
- HTML manifest只包含有限直接图片/经典JS/CSS，不猜模块/CSS递归；manifest外related拒绝，支持的本地资源不混新版。
- ZIP成员及其HTML资源绑定原ZIP ID，正常媒体预览与未知格式下载保留，不公共解压；旧legacy索引继续原语义。
- 版本列表不把本卡换成最新，不把latestDelivered称为当前磁盘文件；正文链接/流式图片也固定到原ID。
- HEAD、Range、If-Range、下载名、跨用户/IP/角色边界保持。
- 新snapshot默认未审核，legacy未关联审核；没有真实批准依据不能显示已批准。
