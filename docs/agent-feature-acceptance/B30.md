## 必须保留的边界

- 本轮不进行真实公开发布；模拟runner的回执不能证明任何真实社媒已发表。
- 可靠ID透传已接XHS userId、抖音uid/sec_uid/open_id、B站已登录nav.mid、视频号finderUsername、知乎本人id。快手/MP现有whoami尚未给出可验证本人账号ID，明确unknown并拒绝外发，不能用昵称、会话token、操作员uin、配置标签或随机值代替。严格本人探测仍需继续，非平台永久不支持。
- 现有通用快手readback可把作品author认作账号，不能用于批准；已有current/user本人探测入口可后续严格接入。MP认证页面原始账号结构需实际证据，不能以字段名猜测。
- 新原生线程可注册typed发布；未知旧resume线程不偷换历史ID。ACP尚无相应typed reverse/MCP桥。
- native无界shell/浏览器/MCP不是本业务服务的强批准边界；本项不把prompt当OS安全隔离保证。具体操作能力隔离继续按AUT与权限范围推进。
- 硬重启遗留executing的owner/lease恢复仍属于D30/AUT执行生命周期；当前保留intent阻止重发，不能称恢复或平台最终确认已经完成。
- 审批与公开回执不能互相替代；D30平台确认、对账与恢复仍须继续，整体144项/AUT目标保持未完成。
