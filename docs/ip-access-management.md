# IP 与团队权限管理

左上角「IP 管理」会打开中央选择弹窗。一个 IP 表示一个自媒体品牌，可以连接多个社交平台；切换 IP 后，平台登录态、画像、内容、排期和运营数据一起切换。个人对话与发布草稿再按登录用户隔离。

首次打开升级后的工作台，需要在服务器本机创建平台管理员，密码由使用者自行设置，没有默认密码。原有 IP、内容和账号归属这个初始管理员；同一浏览器的原有对话会迁入该用户的私人空间。

平台管理员从侧栏底部「用户管理」创建账号、重置密码或停用账号。密码由平台管理员统一管理。重置密码、停用或退出会撤销旧会话；不同浏览器可分别登录不同用户，同一浏览器多个标签页会同步感知登录变更。

在「IP 管理 → 新建 / 管理 IP → 成员」添加平台用户并选择角色：

| 能力 | owner 负责人 | operator 运营者 | viewer 查看者 |
| --- | --- | --- | --- |
| 浏览 IP 内容、排期和运营记录 | ✓ | ✓ | ✓ |
| AI 对话、创作、上传与内容排期 | ✓ | ✓ | — |
| 受控发布、审核和互动处理 | ✓ | ✓ | — |
| 连接、退出或配置社交账号 | ✓ | — | — |
| 修改 IP、分配或移除成员 | ✓ | — | — |

平台管理员是独立的全局权限，用来管理平台用户、模型和本机工具；它不会自动授予未加入 IP 的内容访问权。每个 IP 必须保留至少一位有效 owner。成员变更会在后续请求重新检查，进行中的流式响应也会检查撤权。

团队成员的 AI 对话使用不带宿主文件与命令工具的兼容模型 API。模型由平台管理员配置；普通 IP owner 不会因此获得服务器工具权限。原始视频编辑器仅向平台管理员开放，运营者通过受控制作接口处理视频。

视频画布、渲染回执和互动账号凭据都核对 IP 归属。已保存的旧画布需要重新安全连接后才能继续调用编辑运行时。独立制作运行时应保留在服务端私有网络；本次 Web 登录不替代该独立服务自身的部署边界。

手动提交、真实平台发布和模拟互动在界面中分别标记；本地权限验收不会登录或发布到真实社交平台。已提交给社交平台的操作以真实回执为准，撤权不能撤销已经完成的公开操作。
